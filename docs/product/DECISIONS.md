# 設計判断 v0.2

## ADR-001 製品名

- 表示名: 暮らしと資産プランナー
- repository: Personal-Finance-Planner
- 理由: 家計だけでなく手取り・資産形成まで扱うため

## ADR-002 local-first

初期版はバックエンドを持たずブラウザ内保存とJSON移送を採用する。複数端末同期は対象外とする。

## ADR-003 Vite + TypeScript + Vanilla UI

計算・制度・データ型の取り違えをTypeScriptで抑えつつ、UIフレームワーク依存を避ける。

## ADR-004 SPAページ型タブ

トップレベルタブは一時的なtabpanelではなく、URL・履歴を持つページ遷移として実装する。

## ADR-005 連携値は参照

手取りや掛金を連携先へコピーせず、source参照から再計算する。manualへ変更する場合は明示的にlinkを解除する。

## ADR-006 二重計上を構造で防ぐ

生活費と資産形成拠出を異なるkindにし、`sourceType + sourceId`一意性で重複を拒否する。名称類似判定を正本にしない。

## ADR-007 制度ruleを有効期間で解決

特定年度のif分岐ではなく、metadata付きruleと汎用Resolverを使用する。期間重複・空白・境界を自動検証する。

## ADR-008 未対応保険料を推測しない

組合健保・共済等へ協会けんぽ料率を代用せず、手入力または未計算表示とする。

## ADR-009 グラフはMVP必須外

最初は数値・表・警告を優先する。自前SVG/Canvas実装は行わず、必要になった段階でライブラリを比較する。

## ADR-010 段階リリース

3ドメインの完成を一度に目指さず、横断スパイク、家計、手取り、資産形成、統合の順に提供する。

## ADR-011 実装レビュー最大3回

2回不通過後は非必須項目だけを限定緩和し、3回目不通過でレビューを打ち切ってユーザー判断へ移す。計算・データ保全・build/test等は緩和しない。
