# 要件定義 v0.2

## 1. 製品識別

- アプリ表示名: 暮らしと資産プランナー
- 英語名: Personal Finance Planner
- repository: `Osato-Gasu/Personal-Finance-Planner`
- 対象地域: 日本
- 対象利用者: 個人、本人と同棲相手または配偶者の最大2名
- 位置付け: 家計・手取り・資産形成の概算支援ツール

## 2. 目的

利用者が次の順序で現在と将来のお金を把握できることを目的とする。

1. 給与・賞与から法定控除後の手取りを概算する。
2. 日・週・月・年単位で発生する生活費を月額等へ平準化する。
3. 同棲時の共同費を全体、カテゴリ、費目ごとの割合で分担する。
4. NISA・iDeCoへの拠出後に残る金額を確認する。
5. 積立元本、運用益、将来残高、制度上限を試算する。

## 3. 画面構成

トップレベル画面はURLを持つSPAページとし、見た目をタブ型ナビゲーションにする。

| 画面 | route | 主目的 |
|---|---|---|
| 総合サマリー | `#/overview` | 全モジュールの主要結果を統合表示 |
| 家計・生活費 | `#/budget` | 支出平準化、カテゴリ、負担割合 |
| 手取り計算 | `#/take-home` | 給与、税、社会保険、手取りの概算 |
| NISA・iDeCo | `#/investments` | 積立、上限、将来資産、節税効果 |
| 設定 | `#/settings` | 人物、制度年月、保存、バックアップ |

再読み込み、戻る、進む、URL直開きに対応する。画面切替で保存済み入力を失わない。

## 4. 共通プロフィール

最大2名を管理する。

- 本人
- 同棲相手または配偶者

人物ごとに表示名、生年月日、居住都道府県、収入計画、NISA計画、iDeCo計画を保持する。NISA・iDeCoの上限判定と資産は人物単位とし、世帯合算値は表示専用とする。

## 5. 総合サマリー

次を月額中心に表示する。

- 額面収入
- 法定控除後手取り
- 生活費
- 生活費後手残り
- NISA拠出額
- iDeCo掛金
- 投資後手残り
- 本人と相手それぞれの負担額・手残り
- NISA・iDeCoの元本、運用益、想定残高
- 適用制度、制度確認日、未対応条件
- 支出超過、制度上限超過、古い制度データ、バックアップ未実施の警告

3種類の残額を混同しない。

```text
法定控除後手取り = 額面収入 - 税 - 社会保険料
生活費後手残り = 法定控除後手取り - 生活費
投資後手残り = 生活費後手残り - NISA拠出 - iDeCo掛金
```

## 6. 家計・生活費

### 6.1 カテゴリ

追加、編集、並び替え、無効化、削除を行える。

- カテゴリ名
- 説明
- 既定負担割合
- 表示順
- 有効状態

費目が所属するカテゴリは直接削除させず、別カテゴリへの移動または無効化を要求する。

### 6.2 費目

次を入力する。

- カテゴリ
- 用途
- 1回あたりの出費
- 周期値
- 周期単位: 日、週、月、年
- 周期内回数
- 費目範囲: 共同、本人、相手
- 負担割合: 継承または個別
- メモ
- 有効状態

追加、編集、複製、無効化、削除、検索、絞り込み、並び替えを行える。

### 6.3 負担割合

共同費だけに適用し、優先順位は次とする。

```text
費目設定 > カテゴリ設定 > 世帯全体設定
```

本人側を0.1%単位で入力し、相手側は100%との差分として求める。個人費とNISA・iDeCoには共同費の割合を適用しない。

### 6.4 入力モード

- 詳細集計: 費目の平準化額を合計
- 簡易集計: 月間生活費合計を直接入力

モード切替で既存費目を削除しない。簡易集計ではカテゴリ・費目別割合を使わず、世帯全体割合だけを使う。

## 7. 手取り計算

### 7.1 初期対象

- 日本国内の給与所得者
- 本人と相手を個別計算
- 年収入力または月給・賞与入力
- 所得税、住民税、厚生年金、健康保険、介護保険、雇用保険の概算
- iDeCo掛金控除
- 協会けんぽ、または社会保険料手入力

### 7.2 明示的な非対応

組合健保、共済組合等を選んだ場合に協会けんぽ料率を自動適用しない。次のいずれかを要求する。

- 保険料を手入力する。
- 未計算のまま結果から除外し、未対応警告を表示する。

### 7.3 入力

- 対象人物
- 対象年月
- 生年月日
- 居住都道府県
- 年間給与または月給
- 賞与
- 非課税通勤手当
- 前年所得
- 扶養・配偶者・障害者等の控除条件
- 生命保険料控除等
- iDeCo掛金
- 健康保険種別
- 必要な手入力保険料

### 7.4 出力

- 額面収入
- 給与所得
- 各税・社会保険料
- 年間手取り
- 月平均手取り
- 控除率
- iDeCo適用前後の税額差
- 計算できなかった項目
- 適用した制度ルール

実際の給与明細との差が生じる要因を結果画面に表示する。

## 8. NISA・iDeCo

### 8.1 共通

- 対象人物
- 開始年月
- 終了年月または目標年齢
- 現在残高
- 取得額または拠出元本
- 毎月積立
- 臨時拠出
- 想定年利
- 年間費用率
- インフレ率
- 月初・月末拠出
- 弱気、標準、強気の保存可能なシナリオ

アプリは商品や利回りを推奨しない。

### 8.2 NISA

制度ルールから次を検証する。

- 年間投資枠
- 枠種別
- 生涯または保有限度
- 対象年月
- 人物ごとの使用額

元本、運用益、想定残高、枠残量、枠を使い切る時期を表示する。MVPでは売却による翌年以降の枠再利用は対象外とする。

### 8.3 iDeCo

加入区分、企業年金等の有無・掛金相当額、本人掛金、現在残高、手数料、受取開始年齢を入力する。

- 制度上限
- 年間掛金
- 元本
- 運用益
- 想定残高
- 所得税・住民税の推定軽減額
- 税軽減後の実質負担

受取時課税を実装するまでは、想定残高が受取税引前であることを明示する。

## 9. ツール間連携

各値の正本を固定する。

| 値 | 正本 |
|---|---|
| 額面給与・賞与 | 手取り計算 |
| 法定控除後手取り | 手取り計算結果 |
| 生活費 | 家計・生活費 |
| NISA拠出 | NISA計画 |
| iDeCo掛金 | iDeCo計画 |
| 投資後手残り | 総合計算結果 |

連携値はコピー保存せず、正本への参照から再計算する。正本更新時は連携先へ即時反映する。手入力へ変更する場合だけ、利用者が明示的に連携解除する。

生活費と資産形成拠出を別データ種別にし、名称や金額の類似比較ではなく`sourceType`と`sourceId`で構造的に二重計上を防ぐ。

## 10. 保存とバックアップ

- 初期版はlocalStorageをRepository経由で使用
- スキーマバージョンとマイグレーションを持つ
- 有効な変更を自動保存
- 破損データを自動上書きしない
- JSONエクスポート・インポート
- インポート前の完全検証と確認
- 最終バックアップ日時の表示
- 定期バックアップ通知
- 複数端末同期は対象外
- 端末間移行はJSONで行う

## 11. 非機能要件

- 金額は円単位整数で保持
- 負担割合はbasis pointsで保持
- 計算ロジックをDOM・保存処理から分離
- 同じ入力・同じルールでは同じ結果
- 360px以上の画面幅に対応
- キーボード操作、フォーカス表示、ラベル関連付け
- 色だけで状態を表現しない
- ユーザー入力を未エスケープHTMLとして挿入しない
- 初期版の実行時外部依存を持たない
- ビルド、テスト、lintをCIで実行
- 計算結果に概算・適用制度・未対応条件を表示

## 12. 段階リリース

「完成形」と「初期提供」を分ける。

1. M0: ガバナンス導入
2. M1: 基盤と横断アーキテクチャスパイク
3. M2: 家計・生活費MVP
4. M3: 手取り計算ベータ
5. M4: NISA・iDeCoベータ
6. M5: 統合サマリーと連携を含む統合MVP

各マイルストーンは単独でビルド・テスト可能にする。

## 13. 初期対象外

- 銀行、カード、証券口座との自動連携
- ログイン、クラウド同期
- 3名以上の世帯
- 確定申告書作成
- 個人事業・事業所得の厳密計算
- 組合健保等の料率自動収集
- 住宅ローン控除・ふるさと納税上限の厳密計算
- 投資商品の推奨
- NISA売却後の枠再利用
- iDeCo受取時課税
- 高度なグラフ
- PWA、ネイティブアプリ

## 14. 全体受入条件

- 各画面をURLから開き、戻る・進むが機能する。
- 画面切替で保存済みデータを失わない。
- 本人と相手のデータ・制度枠を混同しない。
- 費目を日・週・月・年で平準化できる。
- 負担割合の3階層優先順位が機能する。
- 2名の負担額合計が共同費合計と一致する。
- 連携値が正本更新後に自動更新される。
- 連携解除なしに手入力で連携値を上書きできない。
- NISA・iDeCo拠出を生活費と二重計上しない。
- iDeCo控除効果と掛金を二重計上しない。
- 制度有効期間の境界日で正しいルールを選ぶ。
- ルール期間の重複・空白を検出する。
- 未対応保険種別に協会けんぽ料率を適用しない。
- 不正JSONで現在データを失わない。
- 再読み込み後にデータを復元できる。
- 最終バックアップ日時と通知が機能する。
- 重要計算に自動テストがある。
- `npm run build`、`npm run test`、`npm run lint`が成功する。
- スマートフォン幅とキーボードで主要操作が可能。
- すべての制度計算結果に概算・適用ルール・未対応条件を表示する。
