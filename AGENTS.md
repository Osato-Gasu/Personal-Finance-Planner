# Personal Finance Planner bootstrap

1. Read the exact Shared commit selected by `docs/ai/SHARED_RULES.lock.yml`.
2. From that commit, read Shared `AGENTS.md`, then the Shared owners required
   for the current TASK.
3. Read `docs/ai/PROJECT.md` as the sole owner of this Project's permanent
   human-readable rules.
4. Read `docs/ai/PROJECT_ADAPTER.psd1` only when exact Project paths or
   commands are needed.
5. Read only the explicitly assigned `docs/ai/tasks/TASK-xxx.md` and its
   handoff/evidence required for the current decision.

The hierarchy is Shared -> Project -> TASK. Generated views, reports,
handoffs, and historical evidence are not additional rule or TASK-state
owners.
